# Current state

## Status

- `src/main.rs` owns CLI arguments; `src/chat/` handles chat, models, and sessions; `src/pi/` owns the long-lived Pi RPC child/protocol and extension dialogs; `src/tui/` owns input and rendering. `docs/` and `CONTRIBUTING.md` document these boundaries and development workflows. Sessions persist in Pi; `/new`, `/quit`, `--continue`/`/continue` (latest session), and `--sessions`/`/sessions` work without restarting the process for in-chat switching. One-shot prompts are still saved as separate sessions.
- Resume and switches show up to the last five user turns and their assistant text via Pi `get_messages`; the picker reads Pi's persisted JSONL files for the current workspace.
- Interactive terminal chat uses raw-mode `/dev/tty` input for Esc cancellation and Pi extension dialogs (`confirm`, `select`, `input`, single-line `editor`). The reader now uses a separate nonblocking open and bounded `select` waits, preventing blocking reads from trapping handoff shutdown. Auth PTY fixtures share a bounded, deadline-driven harness with process-group cleanup and captured-output diagnostics. Non-interactive dialogs cancel rather than approve; Esc clears queued messages and aborts the current Pi run.
- `/models` switches models for the current provider over Pi RPC. Full-screen selection uses a five-row picker (`src/tui/picker.rs`, reused by `/sessions`) docked above the composer and aligned with its outer margin, with active model marker, arrow/wheel/PageUp/PageDown navigation, Enter selection, Esc cancellation, and a moving viewport/scrollbar. Typing `/` in the composer opens live prefix-filtered suggestions for supported Hibiscus commands (`src/chat/commands.rs`); Up/Down/wheel navigate, Tab completes, Enter runs, Esc dismisses. Line mode retains numbered input. In full-screen mode `/login` now offers an explicit Codex/other-provider picker regardless of the active model, which may be absent or different after logout. Codex uses `src/pi/auth.rs` and the embedded Node helper (`codex-auth.mjs`) for Pi's SDK OAuth flow and reconnects the idle RPC child on success. Browser sign-in now uses an OSC 8 short hyperlink and optional Ctrl+Y OSC 52 clipboard request rather than wrapping/truncating the long OAuth URL in transcript text. The mock SDK PTY suite tests browser completion, device selection, masked manual input, empty chats, cancellation, and same-session reconnection. The post-login freeze was reproduced in a live user run: browser showed OAuth success while Hibiscus remained in `/login`. Process inspection found Hibiscus blocked waiting for the Node helper, which retained an established localhost callback socket after closing its listener. Auth now treats the helper's completion event as authoritative and terminates/reaps it rather than waiting for browser connections to close; a local-socket PTY regression covers this. `/logout`, other providers, and unavailable Node/SDK still hand off to Pi's TUI; Hibiscus now closes the RPC child before the handoff, opens Pi on the saved session or `--no-session` for an empty chat, and reopens the RPC child afterward. Neither auth path requires a saved chat message.
- `install.sh` provides checksum-verified prebuilt installation to a user-writable directory for Linux musl and macOS on x86-64/ARM64. `.github/workflows/ci.yml` checks formatting, Clippy with warnings denied, and installer behavior on Ubuntu, plus Rust tests on Ubuntu and macOS for pushes/PRs to `dev` only; `main` does not trigger CI. `.github/workflows/release.yml` repeats quality checks, builds all four targets, ad-hoc signs macOS binaries, generates `SHA256SUMS`, and publishes tagged GitHub releases. `hibiscus --version` supports installation checks; `tests/install.sh` covers Linux/latest and macOS/version-pinned selection with mocked downloads.
- Interactive chat uses an alternate-screen display (`src/tui/screen.rs`) with a fixed composer, raspberry-pink flower accents, short Pi model/session status, and Markdown-formatted transcript (`src/tui/markdown.rs`). While a prompt is active, the flower cycles and a raspberry-pink footer shows working/thinking/writing/tool phase and elapsed time even if Pi is silent. RPC tool start/end events show themed read/write/edit paths and success/failure, plus a reasoning-duration note. Successful built-in edits display a bounded, color-coded preview sourced from Pi's `result.details.diff`; failures show no diff. Raw reasoning and other full tool results remain hidden. Mouse-wheel and PageUp/PageDown scroll while idle or streaming; the viewport stays anchored as new text arrives and stops at the oldest full page, not an almost-empty screen. Pi's original Markdown and session history are unchanged. The terminal screen is restored on exit/auth handoff; `src/tui/ui.rs` handles transcript labels and line-mode fallback. Piped input/output remains plain.
